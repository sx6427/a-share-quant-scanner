# A股异动扫描器 (MiMo 申请项目)

## 项目背景
作为一个独立开发者，我每天下班后只有 1 小时看盘，根本翻不完 5300 多只 A 股。
以前靠肉眼刷涨幅榜，效率低且容易被情绪误导。现在用这套脚本做“初筛 + AI 复盘”。

## 工作流程
1.  **Scanner (`scanner.py`)**:
    *   收盘后自动拉取全市场数据。
    *   剔除 ST 和垃圾股，筛选出放量突破的标的（比如涨幅>3%且量比>1.5）。
    *   输出 `anomaly_stocks.csv`。

2.  **Analyzer (`analyzer.py`)**:
    *   读取筛选出的股票。
    *   将每只股票的**量价特征**封装成 Prompt。
    *   调用 **MiMo API** 进行深度逻辑归因（判断是主力进货还是诱多）。
    *   输出 `analysis_report.txt`。
